ARMUX TERMINAL
오른쪽 위 + 버튼 또는 Ctrl/⌘ + N 으로 SSH 세션을 시작하세요.
Ctrl + 숫자 서브탭(가로 줄) 이동
Ctrl + Alt + 숫자 메인탭(세로 열) 이동

서브탭 왼쪽 📁 파일 파일 탐색기 (📌 로 왼쪽 고정)

Ctrl + ` 파일 탐색기  ·  Ctrl + Alt + ` 메모장

웹페이지 주소
이 판에 크롬(Chromium) 화면이 뜹니다. 주소창과 뒤로/앞으로·새로고침을 씁니다. 크롬 로그인 세션은 가져올 수 없습니다 — 필요하면 주소창 오른쪽 "크롬에서 열기" 로 진짜 크롬에 넘길 수 있습니다.
